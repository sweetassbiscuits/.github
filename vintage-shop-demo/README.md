# [SHOP NAME] demo site

A visual demo of a vintage shop: plain HTML and CSS with a little JavaScript, no build step.
Open `index.html` in a browser, or drag this folder onto Netlify Drop.

Pages: `index.html` (home), `shop.html` (filterable grid), `product.html` (sample ring),
`about.html`, `drops.html`.

- Sample products live in `assets/products.js`.
- Styles live in `assets/styles.css` (colors at the top).
- Placeholders to fill in are in square brackets, like `[SHOP NAME]`, `[HER NAME]`, `[TOWN]`.
- Compare hero lines with the 1 / 2 / 3 buttons on the homepage, or add `?hero=2` to the address.
