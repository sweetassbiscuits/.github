## Reservations

`reservations.html` is a standalone page that embeds the Toast reservation widget.
To add the widget to any other page, paste this where the booking form should appear:

```html
<div id="toast-booking-widget"></div>
<script
  src="https://toast.app/scripts/widgets/reserve.js"
  data-restaurant-guid="bd820884-9bf3-4388-b309-4b39f2186c28">
</script>
```
